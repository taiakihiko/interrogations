## 事件の概要 (共通情報)

## 事件の真相

佐藤は研究費を横領していた。
田中所長は横領を発見し、佐藤を追及していた。

佐藤は友人の山川と共謀し、アリバイ作りのため駅で鞄の置き引きを偽装した。
山川は佐藤の鞄を持ち去り、社員証を抜き取った。
佐藤は置き引き被害を警察に届け出ていた。

しかし山川は秘密裏に21:55に佐藤と堕ち合い、社員証を佐藤に返却した。
佐藤は22:10に社員証を使って研究所に入館し、22:20に田中をナイフで殺害した。
佐藤は22:35に研究所を退館した。
